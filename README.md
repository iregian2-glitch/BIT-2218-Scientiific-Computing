# BIT 2218 – Scientific Computing

## Project Overview

This repository contains the practical work for BIT 2218 Scientific Computing. It covers numerical methods and computational techniques implemented using Python.

## Tasks Covered

The project contains the following areas:

- NumPy arrays and vectorization
- Numerical errors
- Matrix operations
- Systems of linear equations
- Gaussian elimination and LU decomposition
- Iterative methods
- Eigenvalues and eigenvectors
- Root finding
- Polynomial and nonlinear equations
- Interpolation and curve fitting
- Numerical differentiation and integration
- Ordinary differential equations
- Numerical optimization
- Random numbers and Monte Carlo methods

## Requirements

The programs use Python and the following libraries:

- NumPy
- SciPy
- Matplotlib

## Installation

Install the required libraries using:

bash
python -m pip install numpy scipy matplotlib


## Running the Programs

Navigate to the project directory and run an individual task using:

bash
python code/Task_02_numpy_arrays.py
